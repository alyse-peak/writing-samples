# Documentation Strategy & Information Architecture

These adapted artifacts demonstrate the documentation frameworks I developed to support a transition from legacy, document-centric content toward a modular, task-oriented knowledge base. They reflect original work on content classification, editorial governance, and documentation consistency.

## [Metadata Standards](metadata-standards.pdf)
**Challenge:** Create consistent attributes for finding, managing, and maintaining content across products and workflows.

**My contribution:** Defined content discovery and content governance fields, including product, task, audience, content type, lifecycle status, and review ownership.

**Demonstrates:** Metadata architecture, governance, taxonomy alignment, and maintainability.

## [Task Taxonomy](task-taxonomy.pdf)
**Challenge:** Organize technical content around user goals rather than internal product boundaries.

**My contribution:** Developed the Learn, Deploy, Operate, Protect, Monitor, and Automate classification model, with supporting subcategories and rationale.

**Demonstrates:** Task-oriented information architecture, navigation strategy, and content organization.

## [Documentation Style Guide](documentation-style-guide.pdf)
**Challenge:** Establish consistent, actionable documentation across products and contributors.

**My contribution:** Authored principles for user-outcome-focused writing, procedures, UI conventions, diagrams, linking, and technical review.

**Demonstrates:** Editorial governance, documentation standards, and cross-functional review design.

*These samples are adapted and anonymized from original professional work. They are not official client documentation.*
